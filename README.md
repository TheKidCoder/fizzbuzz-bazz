# FizzBuzzBazz

A twist on the classic FizzBuzz kata.

## Rules

- Multiples of 3 print `Fizz`
- Multiples of 5 print `Buzz`
- Multiples of 7 print `Bazz`
- Shared multiples combine the words, e.g.:
  - 15 -> `FizzBuzz`
  - 21 -> `FizzBazz`
  - 35 -> `BuzzBazz`
  - 105 -> `FizzBuzzBazz`
- Otherwise, print the number itself

## Usage

```bash
python3 fizzbuzz.py
```

Prints the result for numbers 1 through 100.
